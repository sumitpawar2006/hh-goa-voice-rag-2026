# Social submission checklist

The required posts are human/account actions. Check an item only after opening the public post URL and verifying its content.

For every individual team member:

- [ ] Team/process video uploaded to Instagram.
- [ ] Product demo uploaded to Instagram.
- [ ] Team/process video uploaded to X.
- [ ] Product demo uploaded to X.
- [ ] Each post contains `#RAGInGoa` exactly.
- [ ] Caption identifies Hacker House Goa 2026 and the project.
- [ ] Video plays to completion with audio.
- [ ] Public post URLs saved to the submission sheet.

Team-wide:

- [ ] At least one Instagram account is public.
- [ ] Public visibility verified from a signed-out/incognito window.
- [ ] No API keys, private prompts, personal data, or credentials appear in footage.
- [ ] Deadline check uses India time: August 22, 2026 at 11:59 PM.

This repository intentionally does not claim these actions are complete without verified URLs.
